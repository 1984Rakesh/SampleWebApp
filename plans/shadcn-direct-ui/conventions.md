# Conventions: shadcn direct UI
Follows plans/RULES.md. Rules below apply to every task in this plan.

## Design source
- The Tasks App DS lives in `plans/shadcn-direct-ui/design-system/`: `README.md` (brand book), `globals.css` (tokens), `tokens.json` (type scale, spacing), `components/<Name>.md` (guidelines), `components/bundle.js` (reference implementation: the exact Tailwind class strings to copy), `components/index.d.ts` (prop shapes). Read README.md and the `.md` for every component your task touches.
- Ignore the DS README's setup steps 1–4 and `pnpm` commands: Tailwind v4, aliases and `components.json` already exist. This repo uses **npm**.
- The DS `bundle.js` is reference only; never import or copy it into `src`. Its `Icon` maps to `lucide-react` (`check`→`Check`, `check-circle`→`CircleCheck`, `clock`→`Clock`, `list`→`List`, `trash`→`Trash2`, `logout`→`LogOut`, …).

## Styling
- Never write hex/rgb colours in `src` outside the theme CSS; use token utilities (`bg-card`, `text-muted-foreground`, `bg-priority-high`, `border-divider`, …).
- Fonts: `font-display` (Bricolage Grotesque) for page/card/dialog titles and stat numbers; `font-sans` (DM Sans) for the rest. Type sizes from `tokens.json` (`display-xl` 42/46 bold, `display-lg` 28/32, `display-md`, `stat`, …).
- Radii: inputs/buttons `rounded-md`; stat cards `rounded-card`; content cards `rounded-xl`; dialog `rounded-2xl`; badges/nav pills `rounded-full`.
- Page content `mx-auto w-full max-w-[1200px] px-8` (Profile `max-w-[1000px]`); sections `gap-6`/`gap-8`; card padding `p-5`–`p-7`. Must work at 375px (use `px-4 sm:px-8`, stacking grids, horizontally scrolling tables).
- No emoji, no exclamation marks, sentence case labels. Priority/status always show the word.
- Icon-only buttons have `aria-label`. Focus: `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2`.
- No opacity modifiers on token colours (`bg-primary/50`).

## Architecture (overrides RULES.md where they differ, once P2.T1 merges)
- shadcn primitives are generated by the CLI into `client/src/components/ui/<lowercase>.tsx` and exported from the `components/ui` barrel together with `cn` and `SelectOption`. Consumers import from the barrel, never from the file.
- After P2.T1: feature `presentation/screens|components`, `src/components/layout|feedback` and `src/app/` may import the `components/ui` barrel, `lucide-react` and `cn`. Domain, data, foundation, shared, and presentation `models`/ViewModels still may not.
- Before P2.T1 merges, shadcn and lucide imports stay inside `components/ui` and `components/app`.
- Screens/components render ViewState and primitives only; ViewModels, hooks, handlers, routes, test ids and API/session contracts do not change.
- Task-specific UI (task table, task badges mapping, task dialog) stays in `tasks/presentation/components`; dashboard uses its own display contracts plus generic `components/app` pieces (StatCard, ChecklistRow). No new cross-feature imports.
- A new file must be imported in the same task (no-orphans rule).

## Ui* → shadcn mapping (Phase 3)
- `UiFlex`, `UiStack`, `UiGrid`/`UiGridItem`, `UiPage`, `UiScreen`, `UiContainer`, `UiAsideGrid`, `UiResponsive` → `div`/`section`/`main` + Tailwind flex/grid classes.
- `UiText` → `h1`–`h3`/`p`/`span` + DS type classes. `UiCode` → `pre`/`code` + Tailwind.
- `UiCard*`, `UiPaper`, `UiTonePanel` → `Card`, `CardHeader`, `CardTitle`, `CardContent`, `CardFooter` (or a `div` with `rounded-xl border bg-card`).
- `UiButton`, `UiIconButton`, `UiNavButton`, `UiLink`, `UiPressable` → `Button` (`asChild` around router `Link`/`NavLink` for navigation).
- `UiTextField`, `UiSearchField` → `Label` + `Input`/`Textarea`, error text below the field (`text-sm text-destructive`), `aria-invalid`, `aria-describedby`.
- `UiSelect` → `Select*`; `UiToggleGroup`, `UiTabs` → `ToggleGroup`; `UiCheckbox` → `Checkbox`.
- `UiChip` → `Badge` variant; `UiAlert` → `Alert`; `UiDialog` → `Dialog*`; `UiTable*` → `Table*`; `UiDrawer`/`UiNavList` → `Sheet`; `UiAvatar` → `Avatar`; `UiDivider` → `Separator`; `UiProgress` → `Progress`; `UiCircularProgress` → lucide `Loader2` with `animate-spin` (respect reduced motion as today); `UiIcon` → lucide icon; `UiSnackbar`/`UiToastHost` → `sonner`; `UiSwatch`, `UiList`, `UiFormFooter` → plain markup.
- Types `UiChipTone`, `UiIconName`, `UiTextVariant` etc. used in presentation models become feature-owned string unions in the same models file.
