**Findings** (fix tasks; not fixed here)
- F1 Seeded tasks show "Invalid Date" (dashboard and table). `formatDueDate` in `tasks/presentation/models/taskPresentation.ts` builds `isoDate + 'T00:00:00'`, but the seed stores full ISO timestamps (`2026-10-27T16:21:19.005Z`). Tasks created in the app (date input sends `YYYY-MM-DD`) render correctly ("Fri 30 Oct"). Pre-existing on `main` since 2fca468, not from this migration. Fix: parse the date part (`isoDate.slice(0, 10)`) or seed `YYYY-MM-DD`.
- F2 Tasks status filter overflows at 375px: the toggle group is ~365px wide and runs past the 16px gutter to the screen edge ("Done 1" clipped). Fix: let it scroll or wrap (`max-w-full overflow-x-auto`, or full width with shrinking items).
- F3 Row checkbox names are generic and misleading: every row is "Complete task" / "Reopen task" (no title), and clicking "Complete task" moves To do → In progress, not Done. Fix: include the title and name the real action, or make the checkbox toggle done/undone.
- F4 Closing the delete dialog with Escape drops focus to `body` instead of the row's Delete button (the dialog is opened from state, not a `DialogTrigger`). Fix: restore focus to the trigger (`onCloseAutoFocus`).

**Nits**
- N1 Dates read "Fri 30 Oct"; DS says "Wed, 21 Oct" (comma).
- N2 Edit dialog reuses the create subtitle "Add the details. You can change them later."
- N3 Priority select shows "Medium" without the "Priority:" prefix once a value is picked.
- N4 Register's empty submit shows the browser's native "Please fill in this field." bubble, not the app's error style.
- N5 Comparison: selected concept uses the primary fill next to the header's primary `+`; the 42px title wraps to 3 lines at 375px.
- N6 Mobile drawer has no visible close button (closes on link tap or backdrop).

**Checked and fine:** focus rings visible on inputs and dialog buttons; Escape closes dialogs; badges always carry words, priority dots only on priority badges; no page-level horizontal scroll at 375px; table scrolls inside its card; theme persists across logout.
