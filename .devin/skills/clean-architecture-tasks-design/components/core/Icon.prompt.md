Lucide outline icon (CDN) tinted with currentColor; use for every glyph in the app.

```jsx
<Icon name="calendar" size={14} />
```

- `name`: any Lucide icon id (check, plus, search, calendar, pencil, trash-2, x, sun, moon, log-out, chevron-down, chevron-right, circle-check, clock, list, user).
- `label` makes it role="img"; otherwise aria-hidden.
